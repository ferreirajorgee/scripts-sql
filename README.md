# Scripts SQL

Consultas SQL para explorar dados musicais do banco de exemplo.

## Conteúdo

- [`Script.sql`](Script.sql): consultas de seleção, filtros, junções, agrupamentos e ordenação.

## Consultas disponíveis

O arquivo contém exemplos para:

- listar artistas em ordem alfabética;
- encontrar músicas com mais de cinco minutos;
- listar músicas do gênero Rock;
- relacionar álbuns e artistas;
- encontrar músicas do álbum `Let There Be Rock`;
- listar clientes que moram no Brasil;
- contar músicas por gênero, do maior para o menor total;
- buscar músicas cujo nome contém `Love`.

## Objetivo

Este projeto serve como material de estudo e prática de SQL, especialmente para:

- filtros com `WHERE` e `LIKE`;
- ordenação com `ORDER BY`;
- relacionamentos com `INNER JOIN` e `LEFT JOIN`;
- agregações com `COUNT` e `GROUP BY`.
